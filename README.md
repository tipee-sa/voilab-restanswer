Voilab REST Answer
==========

Response system for REST Apis. Provide standard ways to handle rest responses.

A fork for modern days [![CI](https://github.com/tipee-sa/voilab-restanswer/actions/workflows/ci.yaml/badge.svg)](https://github.com/tipee-sa/voilab-restanswer/actions/workflows/ci.yaml)
==========

This is a fork of `voilab/restanswer` adapted for modern PHP development, which supports :

* PHP `8.1` <-> `8.5`
* PSR-7

The following changes were applied to the dev dependencies :

* PHPUnit for unit tests
* PHPStan for static analysis
* Add GitHub Actions for continuous integration
